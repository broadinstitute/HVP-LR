# Hit threshold for viral-viz

## Decision

**Discovery threshold (default for all plots, count matrix, UMAP):**
```
evalue ≤ 1e-5  AND  bits ≥ 50  AND  alnlen ≥ 50
```

**High-confidence threshold (headline plots, abundance bar top-N):**
```
bits ≥ 300  AND  alnlen ≥ 80  AND  evalue ≤ 1e-10
```

Both thresholds are reported. Plots include the discovery set; the
high-confidence set is highlighted (e.g. annotated in abundance bar,
emphasized in UMAP point alpha).

## Empirical basis

Sampled the m8 from submission `2da383d1` (HVP-0006.1_34P,
752,332 hits, 83 MB) at 10 evenly spaced byte offsets, 3 KB each
(≈ 300 hits total, ≥ 30 distinct queries).

Observed distribution buckets:

| Bucket | bits | typical fident | typical alnlen | typical evalue |
|---|---|---|---|---|
| Tail (~30% of hits) | 199-250 | 0.08-0.15 | 90-280 | 1e-3 to 1e-4 |
| Mid (~40%) | 250-500 | 0.10-0.20 | 200-450 | 1e-5 to 1e-9 |
| Strong (~20%) | 500-1000 | 0.15-0.30 | 250-500 | 1e-10 to 1e-20 |
| Top (~10%) | 1000-2300 | 0.20-0.30 | 350-700 | 1e-20 to 1e-51 |

Key observations:
1. **Foldseek already filters at evalue ≤ 1e-3.** No hits weaker than
   ~9e-4 observed across 300 sampled rows. So the m8 input itself is
   pre-filtered to "marginally significant or better."
2. **No bits below ~200.** Foldseek converts its 3Di Gotoh score to
   bits — the floor reflects the prefilter cap.
3. **Natural regime break around bits ≈ 250-300.** Below this is the
   noise shoulder (low fident, alnlen often < 100, evalue at the 1e-3
   wall). Above is structurally informative.
4. **fident is uninformative for stratification** — even strong hits
   show fident 0.15-0.30. Structural homology preserves fold long
   after sequence identity decays. Do NOT threshold on fident.

## Rationale per criterion

### evalue ≤ 1e-5 (discovery)
- One order of magnitude tighter than foldseek's emitted cutoff (1e-3).
- For ~50k queries × 350k targets = 1.75e10 query-target comparisons,
  expected false hits at 1e-5 = ~175k. We see 752k total → noise
  fraction at 1e-5 ≈ 23%. Acceptable for discovery if downstream
  consensus (multiple hits per virus) compensates.
- Foldseek paper (van Kempen et al., *Nat Biotechnol* 2024) recommends
  e-value < 1e-3 as the **emitted-hit** filter and < 1e-5 for
  **published-finding** confidence in distant-homology surveys.

### bits ≥ 50 (discovery)
- Floor; effectively a no-op given foldseek emits ≥ ~200. Kept as a
  safeguard against pipeline changes that loosen evalue filter.

### alnlen ≥ 50 (discovery)
- Filters domain-fragment hits that match only a tiny structural motif
  without contextual coverage. 50 residues ≈ smallest stable globular
  unit.

### bits ≥ 300 (high-confidence)
- Matches the regime-break observed in this sample. Empirically captures
  the strong + top buckets together (~30% of hits).
- Validate when cohort grows: a per-target null distribution
  (bits ranked across all queries for randomized target) would let us
  set this with a proper FDR. Punted to Phase 7.

### alnlen ≥ 80 (high-confidence)
- Excludes short structural motif matches (single-domain hits to
  multi-domain targets). 80 residues ≈ canonical full small protein.

### evalue ≤ 1e-10 (high-confidence)
- ~5 orders of magnitude tighter than emitted cutoff. Expected false
  hits across the comparison space ~ 1.75 (i.e. essentially zero
  expected by chance).

## What we explicitly do NOT do

- **No fident threshold.** Distant viral homologs share fold with low
  sequence ID; thresholding here biases toward closely related viruses.
- **No best-hit-only filter for counts.** Each passing (query, target)
  hit contributes one occurrence to the virus's count. This boosts the
  signal of viruses with multi-protein matches (more biologically
  informative than single-hit detection).
- **No taxonomy-LCA collapse upstream.** Hits stay at uniprot resolution
  through ingestion. LCA-style virus-level rollups happen downstream
  inside scanpy / anndata as a derived view.

## Methods note for the per-sample report

Each generated plot must carry a footer:
```
filter: evalue ≤ 1e-5 AND bits ≥ 50 AND alnlen ≥ 50
N hits passing: <K of 752,332>; N unique viruses (uniprot): <V>
```

## Revisit triggers

Re-evaluate the thresholds when ANY of:
- Cohort grows to ≥ 3 samples — empirical FDR becomes possible
- Padded-BFVD GPU search rerun changes hit count by ≥ 2×
- Verbose-prostt5 patch reveals GPU offload was failing on prior runs
  (i.e. these hits were generated by a different inference path than
  expected)
